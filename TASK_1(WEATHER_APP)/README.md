# Task 1 : WEATHER APP

## OBJECTIVE:

- To make a simple minimalist weather app
- use opeweathermap api key
- dockerizing the app
- Github Actions
- Deploy to Vercel

## TECHNOLOGIES USED:

- REACT-APP (For Front-End)
- EXPRESS NODE.js (For Back-End)
- BOOTSTRAP (For CSS)
- OPENWEATHERMAP API
- DOCKER

## RUNNING THE APP LOCALLY:

- Clone the repository
- Put your API key in the .env file
- Put your API key in the docker-compose.yml
- Run `docker-compose up --build`

## DEPLOYMENT:

- Deploy to Vercel
- Use Github Actions to automate the deployment

## GITHUB ACTIONS:

- Trigger: Push to main branch
- Workflow: Build and deploy to Vercel
